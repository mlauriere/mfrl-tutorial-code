# MFRL Tutorial Experiments

This folder contains a minimal, runnable version of the numerical experiments used in the MFRL tutorial/book.

## Setup

```bash
conda create -n mfrl-tutorial-oss python=3.11 pip
source ~/opt/anaconda3/bin/activate mfrl-tutorial-oss
python -m pip install -r requirements.txt
python -m pip install -e .
```

If you do not install the package, run commands with `PYTHONPATH=src`.

Jupyter is not required for the runnable code.

## Quick Checks

```bash
PYTHONPATH=src python -m mfrl_tutorial.env_check
bash scripts/run_smoke_local.sh
```

Smoke runs write timestamped outputs under `outputs/smoke/<experiment>/<timestamp>/`. Each run should contain `run.log`, `resolved_config.yaml`, `manifest.json`, and at least one generated artifact.

## Book-Scale Commands

```bash
PYTHONPATH=src python -m mfrl_tutorial.cybersecurity_qlearning --config configs/cyber_qlearning_with_cn.yaml
PYTHONPATH=src python -m mfrl_tutorial.cybersecurity_ddpg --config configs/cyber_ddpg_without_cn.yaml
PYTHONPATH=src python -m mfrl_tutorial.distribution_planning_ddpg --config configs/distribution_planning_with_cn.yaml
PYTHONPATH=src python -m mfrl_tutorial.lq_generate_data --config configs/lq_generate_demo_2seeds.yaml
```

The DDPG and Q-learning book-scale runs can be long. Keep the `run.log` and `manifest.json` generated by each run.
The LQ command is a small data-generation demo rather than a full reproduction of the aggregate book data.

## LQ Data Demo

To run a lightweight one- or two-seed LQ data-generation experiment from scratch:

```bash
PYTHONPATH=src python -m mfrl_tutorial.lq_generate_data --config configs/lq_generate_demo_2seeds.yaml
```

This demo exercises the algorithmic pipeline, but it is not intended to reproduce the smoothed book
aggregate exactly. Full aggregate LQ data are not bundled in this first public version.

## Layout

- `src/mfrl_tutorial/`: importable package and config-driven entrypoints.
- `configs/`: book and smoke YAML configs.
- `scripts/`: local run helpers.
- `docs/`: local setup and reproduction notes.
