# MFRL Tutorial Experiments

Code and reproduction instructions for the current numerical examples in the
MFRL tutorial/book: linear-quadratic mean-field control, cybersecurity and
distribution planning.

## Linear-quadratic figures

The scalar and coupled 2D studies reproduce book Figures 6.1–6.5. See
[the LQ reproduction guide](docs/reproducing_lq_revision.md) for independent
training/resume/analysis, plotting from local results, exact settings and bounded
checks. Both studies use plain constant-step SGD. The repository distributes
code, configurations and documentation only. Training histories, analyzed
datasets and figures are generated locally and excluded from Git.

First run the training and analysis commands in the guide. Once they have
created `outputs/retrained_data`, use an existing interpreter satisfying
`requirements-lq-revision.txt` to plot the results:

```bash
MPLCONFIGDIR="$PWD/outputs/matplotlib-cache" PYTHONPATH=src python -B -m mfrl_tutorial.lq_revision_plot --data outputs/retrained_data --output outputs/revised_figures
```

The plot command generates all 11 required PDF assets without further training
or compilation. `RELEASE_MANIFEST.json` lists the distributed files and hashes.
Generated outputs and local native libraries are excluded. The root MIT
License covers the revision code, configurations and documentation.

## Setup for all examples

```bash
conda create -n mfrl-tutorial-oss python=3.11 pip
source ~/opt/anaconda3/bin/activate mfrl-tutorial-oss
python -m pip install -r requirements.txt
python -m pip install -e .
```

If you do not install the package, run commands with `PYTHONPATH=src`.

Jupyter is not required for the runnable code.

## Quick Checks

```bash
PYTHONPATH=src python -m mfrl_tutorial.env_check
bash scripts/run_smoke_local.sh
```

The smoke script runs one-update scalar and 2D LQ checks without pre-existing
datasets, and exercises the cybersecurity/distribution-planning examples. Outputs
are written under `outputs/smoke/`; LQ training writes per-case logs, histories
and checkpoints plus a sweep manifest.

## Book-Scale Commands

```bash
PYTHONPATH=src python -m mfrl_tutorial.cybersecurity_qlearning --config configs/cyber_qlearning_with_cn.yaml
PYTHONPATH=src python -m mfrl_tutorial.cybersecurity_ddpg --config configs/cyber_ddpg_without_cn.yaml
PYTHONPATH=src python -m mfrl_tutorial.distribution_planning_ddpg --config configs/distribution_planning_with_cn.yaml
```

The DDPG and Q-learning book-scale runs can be long. Keep the `run.log` and `manifest.json` generated by each run.
Full LQ training, resume and analysis commands are in the
[LQ reproduction guide](docs/reproducing_lq_revision.md).

## Layout

- `src/mfrl_tutorial/`: importable package and config-driven entrypoints.
- `configs/`: frozen LQ JSON settings and other examples' YAML configs.
- `scripts/`: local run helpers.
- `docs/`: local setup and reproduction notes.
